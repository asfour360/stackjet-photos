# StackJet lounge photos

Resized copies (JPEG, longest side 1200 px) of the official lounge photos the StackJet app shows,
served with GitHub Pages so links don't break when an operator changes its website.

- `<network>/<airport>/<lounge>-<n>.jpg`
- `manifests/<network>.json` maps each lounge to its photos and their original official source URLs.

Only official photos from the lounge operators and airlines. Priority Pass lounges are not hosted here.
